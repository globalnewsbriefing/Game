# Tablet mount 2D drawing

This folder contains a clean 2D conversion of the supplied manual tablet mount sketch.

## Files

- `tablet_mount_dimensioned.svg` - review drawing with dimensions and assumptions.
- `tablet_mount_profile.svg` - clean vector cutting profile.
- `tablet_mount_profile.dxf` - DXF profile for CAD/CAM import.

## Interpreted dimensions

- Units: millimeters.
- Overall length: 125 mm.
- Overall height: 45 mm.
- Lower hole: 2 mm diameter.
- Upper slot: 59 mm x 2 mm, angled 8 degrees.
- Material thickness noted from the sketch: 2 mm.

The source sketch does not fully define radii, hole/slot center locations, or bend/edge tolerances, so those values were interpreted from the image. Confirm the assumptions before laser cutting.
